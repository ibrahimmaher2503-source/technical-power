## Cards

Shared card radius 16px; border #dfe1e5; white surface; light neutral shadow. Keep service and project cards independently actionable, each with one named destination and a full-area link. Services use red diagonal icon corners, readable descriptions, and bottom-aligned text actions. Previous-work cards use type context and clearly marked illustrative images. Quiet information cards avoid a hover affordance; dark value panels provide contrast. Image proportions, 20–24px body padding and a separated action row establish hierarchy. Compact service cards become horizontal on mobile; project cards stay image-led with stacked content. Honor RTL, keyboard focus and reduced motion.
